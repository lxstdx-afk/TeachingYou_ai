# TeachingYou AI

Персональный AI-ассистент в Telegram для общения, обучения и работы с информацией. Поддерживает отдельные чаты с памятью, поиск в интернете, анализ изображений, поиск книг в PDF и подготовку напоминаний.

## Возможности

- **Меню по запросу.** Команда `/menu` открывает разделы с действиями и подсказками.
- **Отдельные чаты.** Внутри одного диалога с ботом можно создавать и переключать чаты. У каждого — своя история, заметки и режим общения.
- **Память.** Бот формирует заметки по ходу диалога; ими можно управлять вручную. Историю и память можно очистить.
- **Поиск в интернете.** Бот может искать по запросу или автоматически и добавлять ссылки на источники. Если после поиска нейросеть недоступна, показывает найденные ссылки без ответа модели.
- **Книги в PDF.** По названию ищет варианты в открытых каталогах и может отправить выбранный файл в Telegram. Язык, полноту и условия использования стоит проверить на странице источника.
- **Анализ изображений.** Принимает скриншоты и фотографии в форматах JPEG, PNG и WebP.
- **Режимы общения.** Наставник, обычный диалог и поиск идей.
- **Напоминания в Telegram.** Бот подготавливает сообщение с датой; пользователь вручную подтверждает напоминание в Telegram. Оно появляется в «Избранном».

Во время подготовки ответа Telegram может показывать стандартный статус «печатает…». Основные команды доступны в меню бота.

## Основные команды

| Команда | Действие |
| --- | --- |
| `/menu` | Открыть разделы и действия |
| `/new` | Создать чат |
| `/chats` | Открыть список чатов |
| `/remind` | Подготовить напоминание Telegram |
| `/help` | Краткая помощь; `/help all` — полный список команд |

## Технологии

- **JavaScript** и **Telegram Bot API**
- **Cloudflare Workers** и **Workers AI**
- **Durable Objects**, **SQLite** и полнотекстовый поиск **FTS5**
- **Tavily** и **Exa** для веб-поиска; **Wikimedia Commons** и **Internet Archive** для поиска книг

## Данные и доступ

Бот работает в личных сообщениях и доступен только разрешённым пользователям. История и заметки разделены по чатам; пользователь может их удалить. Сообщения, изображения и поисковые запросы могут передаваться внешним сервисам. Для точного времени сохраняется выбранный часовой пояс; текст напоминания обрабатывается ботом и Telegram, но не передаётся модели. Подробнее — команда `/privacy`.
